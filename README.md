# Md. Abir Ahsan - Portfolio

This is the personal portfolio website of **Md. Abir Ahsan**, a Software Engineer specializing in React, Java Spring Boot, and System Integration.

## Project Structure

- `index.html`: The main entry point of the website.
- `assets/`: Contains all static assets.
  - `img/`: Images used in the website (projects, profile).
  - `doc/`: Documents (CV/Resume).
- `scripts/`: Helper scripts used for development (e.g., CV text extraction).

## Technologies Used

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **JavaScript (ES6+)**
- **GSAP** (for animations)
- **Lenis** (for smooth scrolling)
- **Lucide Icons**

## Deployment

This project is static file-based and can be deployed easily to:
- GitHub Pages
- Netlify
- Vercel

Simply upload the files or push to a GitHub repository and enable GitHub Pages on the root directory.
